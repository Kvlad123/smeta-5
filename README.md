# Смета за 5

Offline-редактор смет и коммерческих предложений для фрилансеров. Без подписки, регистрации и передачи клиентских данных.

Возможности полной версии: до 100 проектов, шаблоны услуг, автоматические итоги, скидка и предоплата, печать PDF, JSON-копии, работа без интернета.

Этот репозиторий содержит только публичный сайт. Исходный файл платного редактора и ZIP-комплект покупателя здесь не публикуются.
